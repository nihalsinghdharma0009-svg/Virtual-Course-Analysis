# Virtual-Course-Analysis
## 📖 Overview
This project analyzes a large dataset of Virtual courses to uncover trends in course popularity, language distribution, skill demand, and viewership patterns.
The dashboard provides actionable insights into how online learning platforms are structured and what skills are most in demand.
## 🎯 Objective
Identify the most popular course types and categories
Analyze viewership trends across languages and categories
Discover in-demand skills in the online learning market
Evaluate factors affecting course engagement (duration, subtitles, etc.)
## 🛠️ Tools & Technologies
Power BI (Dashboard Visualization),
Excel / CSV (Data Source),
Data Cleaning & Transformation,
Data Visualization
## 📂 Dataset
Total Courses: 2693
Total Skills: 10,241
Total Viewers: 8.36 Million
## 📊 Key Insights
## Course Type Dominance:
Standard courses dominate the platform with over 2300+ courses, far exceeding specializations and certifications
## Language Trend:
English is the most prominent language, contributing to ~97% of course availability
## Top Categories:
Business (highest number of courses)
Computer Science
Data Science
Highest Viewership:
### Data Science courses receive the highest average viewership
## Most In-Demand Skills:
Data Analysis,
Python Programming,
Machine Learning,
SQL,
Communication,
### Interesting Observations:
No clear relationship between course duration and viewership
Subtitle availability does not strongly impact engagement
